# Бэктест стратегии ставок

Локальный инструмент для проверки стратегии на исторических данных. Сам
скрипт никуда не ходит в сеть и не подключается к букмекерам или
sofascore — он считает метрики по CSV, который вы готовите сами (выгрузка
из своего БК-аккаунта, таблица ваших прошлых сигналов, или данные из
любого источника, доступ к которому есть у вас, но не у этой среды).

## Формат входного CSV

| Колонка        | Обязательна | Описание |
|----------------|-------------|----------|
| `date`         | да          | Дата события |
| `event`        | да          | Название матча/события |
| `market`       | нет         | Рынок (например, "HT 0:0", "П1", "Андердог ML") |
| `odds`         | да          | Кэф, по которому вы бы поставили (взятый кэф) |
| `prob`         | да          | Ваша оценка реальной вероятности исхода (0–1) |
| `result`       | да          | 1 — исход сыграл, 0 — не сыграл |
| `closing_odds` | нет         | Закрывающий кэф рынка (для расчёта CLV) |

`sample_data.csv` — **синтетический** пример только для проверки, что
скрипт считается правильно. Это не реальные матчи и не реальные кэфы,
использовать для выводов о стратегии нельзя.

## Запуск

```bash
python3 backtest.py sample_data.csv --bankroll 10000 --stake-mode flat --flat-pct 2
```

Режим дробного Келли:

```bash
python3 backtest.py your_data.csv --stake-mode kelly --kelly-mult 0.5 --max-pct 5
```

Сохранить подробный лог по каждой ставке:

```bash
python3 backtest.py your_data.csv --export result_log.csv
```

## Что считает скрипт

- EV каждой ставки: `EV = prob * odds - 1`, входит в бэктест только если `EV > --min-ev` (по умолчанию > 0)
- Размер ставки: flat % от банка или дробный Kelly с потолком `--max-pct`
- Winrate, ROI, итоговый банкролл, абсолютная прибыль
- Максимальная просадка банка
- Самая длинная серия проигрышей
- CLV (closing line value) — обогнали ли вы закрывающую линию, если указан `closing_odds`. Это надёжнее winrate, так как meньше зависит от дисперсии

## Важные ограничения

1. **GIGO (garbage in — garbage out).** Если `prob` — это ваша апостериорная подгонка под уже известный результат, бэктест покажет вымышленный эдж. Вероятность должна быть оценкой *до* матча.
2. **Выборка 500+ ставок** нужна для статистической значимости вывода о стратегии — на 30-60 ставках результат может быть случайностью (дисперсия выше сигнала).
3. **Lookahead bias** — не включайте в `prob`/`odds` информацию, которая стала известна после начала события (например, составы, объявленные позже кэфа).
4. **CLV важнее ROI на короткой дистанции.** Стабильный плюс по CLV — более надёжный маркер реального эджа, чем кассовый ROI на малой выборке.
5. Скрипт не делает ставки и не взаимодействует с букмекерами — только расчёт по вашим историческим данным.
